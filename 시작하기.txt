===============================================
   술음료 재고관리 시스템 - PyQt5 데스크톱 버전
===============================================

이 시스템은 로컬 컴퓨터에서 실행되는 독립 프로그램입니다.


■ 빠른 시작 (Windows)
===============================================

1. Python 설치 확인
   - 명령 프롬프트(cmd)를 열고:
     python --version
   - Python 3.8 이상이어야 합니다

2. 패키지 설치
   - 프로젝트 폴더에서:
     pip install -r requirements.txt

3. 프로그램 실행
   - run.bat 파일을 더블클릭
   또는
   - python main.py 명령 실행


■ 빠른 시작 (macOS/Linux)
===============================================

1. Python 설치 확인
   python3 --version

2. 패키지 설치
   pip3 install -r requirements.txt

3. 프로그램 실행
   ./run.sh
   또는
   python3 main.py


■ 첫 사용 시 설정 순서
===============================================

1. 품목 관리 탭
   → "품목 추가" 버튼 클릭
   → 판매하는 제품 정보 입력

2. 쇼케이스 설정 탭
   → 각 쇼케이스의 최대 용량 설정
   → "설정 저장" 클릭

3. 초기 데이터 탭
   → 현재 보유 재고 입력
   → "초기 데이터 저장" 클릭


■ 일일 사용 방법
===============================================

[아침]
1. 입고 관리: 새로 들어온 제품 등록
2. 출고 관리: 쇼케이스로 출고
   (자동 배분 체크 권장)

[저녁]
1. 판매 관리: 실제 판매량 입력
2. 재고 현황: 현재 재고 확인


■ 주요 기능
===============================================

• 품목 관리: 제품 정보 등록/수정/삭제
• 재고 추적: 창고 및 쇼케이스 5개 관리
• 자동 배분: 출고 시 쇼케이스 자동 배분
• 판매 분석: 주간/월간/연간 보고서
• 데이터 백업: 안전한 백업 및 복원


■ 주의사항
===============================================

1. 정기적으로 백업하세요 (최소 주 1회)
2. 데이터는 data/ 폴더에 저장됩니다
3. 프로그램 삭제 전 백업 필수!

• INSTALL.md - 설치 가이드

■ 문제 해결
===============================================

프로그램이 실행되지 않을 때:
1. Python 버전 확인 (3.8 이상)
2. pip install -r requirements.txt 재실행
3. 가상환경 사용 고려


한글이 깨질 때:
[Windows] 일반적으로 문제 없음
[Linux] sudo apt install fonts-nanum


데이터베이스 오류:
1. data/ 폴더 권한 확인
2. 백업에서 복원
3. 데이터베이스 파일 재생성

# 술음료 재고관리 시스템

## 개요
술과 음료의 재고를 효율적으로 관리하기 위한 웹 기반 시스템입니다. SQLite3 데이터베이스를 사용하며, 창고형 냉장고와 5개의 쇼케이스를 관리합니다.

## 주요 기능

### 1. 품목 관리
- 술과 음료 품목 추가, 수정, 삭제
- 품목별 박스당 수량, 개별 판매 단가 설정
- 품목별 비고 관리

### 2. 데이터베이스 구조
- **품목 테이블**: 품목명, 박스당수량, 개별판매단가, 비고
- **창고 재고 테이블**: 날짜별 품목별 박스 단위 재고
- **출고 테이블**: 날짜별 품목별 박스 단위 출고
- **쇼케이스 테이블 (5개)**: 날짜별 품목별 개수 단위 재고, 사용 여부 관리
- **판매 테이블**: 날짜별 품목별 개수 단위 실제 판매
- **초기 데이터 테이블**: 재고 관리 시작 시점의 기준 데이터

### 3. 재고 관리
- 입고: 창고형 냉장고에 박스 단위로 입고
- 출고: 창고에서 쇼케이스로 박스 단위 출고
- 자동 배분: 출고 시 쇼케이스 1부터 순차적으로 자동 배분
- 쇼케이스 간 이동: 쇼케이스 2-5에서 쇼케이스 1로 이동 가능
- 판매: 실제 판매 수량 기록 (주로 쇼케이스 1에서 95% 이상 발생)

### 4. 쇼케이스 설정
- 각 쇼케이스별 품목별 최대 용량 설정
- 품목별 사용 여부 설정 (사용/미사용)
- 쇼케이스 1이 가득 차면 자동으로 쇼케이스 2-5로 오버플로우

### 5. 분석 및 보고서
- **주간 보고서**: 월요일~일요일 단위 분석
  - 예측 판매량 vs 실제 판매량 비교
  - 품목별 차이 분석
  - 차트 시각화
- **월간 보고서**: 주차별 세부 분석
  - 1주차, 2주차 등으로 구분
  - 품목별 주차별 차이 분석
- **연간 보고서**: 월별 추이 분석
  - 12개월 판매 추이
  - 월별 비교 차트
- **품목별 판매 추이**: 특정 품목의 월별 판매 추이 그래프

### 6. 백업 관리
- 데이터베이스 백업 생성
- 백업 파일 복원
- 백업 5년 보관 원칙
- 5년 이후 영구 보관함으로 이동
- 백업 메타데이터 관리

## 사용 순서

1. **품목 등록**: 먼저 판매할 술과 음료 품목을 등록합니다.
2. **쇼케이스 설정**: 각 쇼케이스의 품목별 최대 용량을 설정합니다.
3. **초기 데이터 설정**: 현재 보유중인 재고의 초기값을 설정합니다.
4. **일일 운영**:
   - 입고 데이터 입력
   - 출고 데이터 입력 (자동 배분 옵션 사용 권장)
   - 실제 판매 데이터 입력
5. **재고 확인**: 언제든지 현재 재고 현황을 확인합니다.
6. **분석**: 주간/월간/연간 단위로 판매 차이를 분석합니다.
7. **백업**: 정기적으로 데이터를 백업합니다.

## 데이터 처리 원칙

### 창고 (박스 단위)
- 입고와 출고는 모두 박스 단위로 처리
- 현재 재고 = 초기 재고 + 입고 - 출고

### 쇼케이스 (개수 단위)
- 출고된 박스가 개수 단위로 변환되어 쇼케이스에 저장
- 쇼케이스 1이 우선적으로 채워지고, 용량 초과 시 쇼케이스 2-5로 자동 배분
- 각 쇼케이스별 최대 용량 관리
- 쇼케이스 2-5에서 쇼케이스 1로 이동 가능

### 판매
- 실제 판매는 주로 쇼케이스 1에서 발생 (95% 이상)
- 예측 판매 = 출고량(개수 환산) - 쇼케이스 재고 변화
- 차이 = 예측 판매 - 실제 판매
- 양수: 손실 또는 미기록 판매
- 음수: 예상보다 많은 판매

■ 발생했던 오류
-----------------------------------------------
ValueError: string of length 1 expected

main.py의 폰트 확인 로직에서 발생한 오류


■ 원인
-----------------------------------------------
inFont() 메서드는 단일 문자만 받는데,
폰트 이름 전체 문자열을 전달해서 발생


■ 수정 내용
-----------------------------------------------
1. QFontDatabase 사용
   - 시스템에 설치된 모든 폰트 목록 조회
   - families() 메서드로 가능한 폰트 확인

2. 폰트 우선순위 설정
   - 맑은 고딕 (Windows)
   - Malgun Gothic (Windows 영문명)
   - 나눔고딕 (Linux)
   - NanumGothic (Linux 영문명)
   - Apple SD Gothic Neo (macOS)
   - Noto Sans CJK KR (Linux)
   - Noto Sans KR (Linux)

3. 폴백 처리
   - 위 폰트가 없으면 기본 sans-serif 사용


■ 실행 방법
-----------------------------------------------
python main.py

또는

run.bat (Windows)
./run.sh (Linux/macOS)


■ 확인 사항
-----------------------------------------------
프로그램 실행 시 콘솔에 다음 메시지 표시:
"사용 폰트: 맑은 고딕" (또는 다른 폰트명)

만약 "기본 폰트 사용"이 표시되면
한글 폰트가 설치되지 않은 것입니다.


■ 한글 폰트 설치 (필요시)
-----------------------------------------------

[Windows]
- 기본적으로 맑은 고딕이 설치되어 있음
- 추가 설치 불필요

[Linux - Ubuntu/Debian]
sudo apt install fonts-nanum

[Linux - Fedora]
sudo dnf install google-noto-sans-cjk-ttc-fonts

[macOS]
- 기본적으로 Apple SD Gothic Neo 설치됨
- 추가 설치 불필요


■ 테스트 방법
-----------------------------------------------
1. 프로그램 실행
2. "품목 관리" 탭 클릭
3. "품목 추가" 버튼 클릭
4. 다이얼로그의 입력 필드에 한글 입력
5. 텍스트가 명확하게 보이는지 확인


■ 여전히 글자가 안 보인다면
-----------------------------------------------

1. 폰트 크기 확대
main.py의 298번째 줄:
font.setPointSize(10)
↓ 변경
font.setPointSize(12)  # 또는 14

2. 시스템 DPI 설정 확인
Windows: 디스플레이 설정 > 배율 확인

3. Qt 환경 변수 설정
프로그램 실행 전:
set QT_AUTO_SCREEN_SCALE_FACTOR=1  # Windows
export QT_AUTO_SCREEN_SCALE_FACTOR=1  # Linux/Mac


■ 추가 개선사항
-----------------------------------------------
- 모든 테이블 행 높이: 40-45px
- 입력 필드 최소 높이: 30px
- 버튼 최소 높이: 35px
- 폰트 크기: 10pt (명시적)
- 텍스트 색상: 검정(#000000)
